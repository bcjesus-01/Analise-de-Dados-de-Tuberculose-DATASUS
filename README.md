# Pesquisa para projeto de BI voltado à saúde pública
Este repositório reúne os códigos, relacionados à minha pesquisa do estágio no laboratório de Biotecnologia da Universidade Estadual de Santa Cruz (UESC).
O trabalho é voltada à análise e visualização de dados sobre a Tuberculose provenientes do Sistema de Informação de Agravos de Notificação (SINAN).
